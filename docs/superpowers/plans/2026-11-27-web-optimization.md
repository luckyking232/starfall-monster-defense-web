# 魔物抵御战 Web 优化执行计划

生产基线为 v1.0.1（e31ccaf）。玩家端继续用 Worker 内的 Wasmoon 执行原 Lua，保留原版 FGUI、地图、素材、技能效果与战斗步长。优化集中在网页宿主和发行资源。所有批次从功能分支向 test 提 PR，测试站发布后才进入生产晋级流程。

| 批次 | 实施位置与交付 | 验收与回退 |
| --- | --- | --- |
| 0 发布与存档过渡 | 修改 .github/workflows/game.yml 的触发分支、Pages 上传/部署条件和部署环境白名单；test 与 main 要求 PR/public-preflight、禁强推及删除，管理员同样遵守。在玩家包写入版本指纹。更新 README、CONTRIBUTING 和 Pages 入口。网页设置支持将旧站存档导出为有版本的 JSON、导入新槽；测试存储隔离并保留旧档读取入口 | 检查 GitHub 两条分支的实际保护和环境策略。对比 Pages 提交指纹及在线首页、部署路径。导出两个旧槽并导入已有档的站点；错误文件、配额失败需保住原档。回滚使用已验收的部署和 revert PR |
| 1 手机、声音与纪录 | 从 src/platform/viewport.ts 与 styles/viewport.css 统一布局和触控坐标。音频请求沿 Worker 事件至 presentation/battle-audio.ts、game-audio.ts 按逻辑帧及音源归并，控制声音积压并保持满格 0.10。无尽终局按开局槽位、击杀及波次持久化，选择及结算界面显示，自然/主动退出与 LEVELUP 练习分开 | 同一会话横竖及反向横屏、工具栏和键盘缩放、触点与选卡；同帧九次命中、相邻帧连击、解码后过期请求、循环停止；自然／退出结算、多槽、旧档与重复回调 |
| 2 首屏、首战与包体 | 对 apps/game 的构建与资源解析按窗口、关卡建立依赖；完整原文件保留作源。派生无损 WebP、WOFF2 常用字包与完整后备；构建 BaseWord 中文键闭包，记录动态命中。玩家输出排除诊断脚本和映射，校准资源版本和 HTTP 缓存；选关预备资源，进关等待涵盖解码和关键声音 | 对 16 张原图逐像素比对、核对原字形及任意档名、21 关及窗口词条格式。分别测冷/热首页、首次进关和重入，ZIP 及解码内存。实施前正式首页 65.67 MB，第一阶段目标减半；公开发布前验证动态引用和旧缓存升级 |
| 3 重载战场 | 从 src/presentation/native-world.ts、gl-mesh.ts、FGUI 伤害字与 src/main.ts 帧循环开始。建立可重复第18关回放和真实战场帧时间，复用字形、静态图层和纹理；单一 WebGL 世界原型批绘精灵与粒子，保持深度和混合。拆开有副作用的世界收集与显示快照，离散时序事件保序，连续状态可合并 | 固定种子 70441022、选第一张卡，比较规则帧25–140与1000–1550。基线重载间隔 P95 50.1ms、世界绘制 39.1ms；核对相同帧的敌数、击杀、波次、等级、弹道/效果。正常游戏另跑21关和无尽群伤，保持1/2倍速、暂停、前后台一致。新后端验收前可切回原路径 |
| 4 生产晋级 | 运行输入验证、Vitest、构建、Playwright。按已测 test SHA/树创建到 main 的 PR，CI 和测试站通过后，核对 EdgeOne 正式域实际版本与首战。未达标批次继续留在 test | 在真实中档手机与集显目标分别达到重载30/60 FPS，P95目标36/20ms，记录P99、>100ms卡顿及十分钟温升/内存。设备仅有模拟时单列待验。只有复测仍表明规则计算受限，才迁移具体 Lua 热点 |

每项先复现或建立失败用例，再改正常入口，运行对应回归并记录证据。工程命令在 apps/game 执行：npm run test:inputs、npm run test:unit、npm run build、npx playwright test。各批次的实作与现场验证记录在 STATE.md。
