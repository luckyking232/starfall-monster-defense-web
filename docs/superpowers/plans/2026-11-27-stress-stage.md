# 全技能怪海压测关

在网页设置提供独立压测入口。以同一设备上实际战场画面的最慢时段衡量流畅度。五名角色、各自三项技能、每项三个原版强化词条，每个词条目标三级。同一技能预算九次，受原版上限截断的次数优先移给该技能仍可提升的词条，再移给同一角色的其他合法词条。每名角色合计 27 次，五名角色共 135 次；解锁技能另计。

1. 用原始角色、技能与词条表生成可验证的配置，走原版解锁和强化路径。进入战场即完成配置，压测期间关闭经验升级／选卡。用原 Lua 验证实际已装配技能、层数或叠加效果、上限重分配。
2. 以同一游戏时钟和可重复的怪物序列持续生成活怪。通过原版怪物、移动、战斗、伤害和特效管线制造负载，达到目标密度后按击退补位。压测场独立防止提前终止，退出可回到原主页或选关，普通关与无尽最高分保持各自的结算路径。
3. 从主页及选关的设置进入，显式标识压测。统计实际绘制间隔，报告最差一秒 FPS、P95、P99、最长帧和超过 100 ms 的次数，关联同一慢段的单位、弹体、特效和飘字。暂停、切后台、打开设置和加载时间排除。
4. 验收真实入口、所有原角色的技能、持续补怪、无升级中断、运行与退出、存档隔离和不同帧率下指标口径。在本机实跑高负载片段，把最重时段的数据与模拟 2 倍速、分辨率和渲染路径一起记录。经功能分支 PR 合入 test，核对 Pages 指纹与公网入口，正式站继续按既有流程晋级。
