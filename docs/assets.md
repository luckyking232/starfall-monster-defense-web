# 素材与授权

运行输入对应资源版本 `134395529309427262`。原版 Lua、角色、美术、音频、字体及其他素材分别归各自权利人。项目代码的 MIT 许可证适用于项目自编代码。Wasmoon、Lua 和思源黑体的许可证随运行资源分发，见 [第三方说明](../apps/game/public/assets/licenses/NOTICES.txt)。

`apps/game/public/assets` 提供已准备的游戏输入。界面使用原 FGUI 定义和图集，场景、角色与怪物使用原预制体和精灵帧，技能表现使用原材质、网格、贴图与发射器配置。游戏入口根据原 Lua 产生的位置、朝向、挂点、等级和生命周期绘制。Unity 与浏览器的随机粒子采样有实现差异。

核对运行输入使用 `npm run check:inputs`。检查当前小游戏的实际特效调用、仅配置的路径和同包未引用对象，可用 `scripts/audit_presentation_assets.py` 对配套原始研究资料重建清单。不同场景共用的图集会含有本小游戏用不到的条目。[五名角色的特效与逐级核验](effects.md)。
