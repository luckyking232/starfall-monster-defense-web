# v1.0.0 战斗表现核验

按游戏资源版本 `134395529309427262` 检查了 43 条候选特效路径。原小游戏实际会创建 24 个 prefab，覆盖 23 个战场效果和 1 个战斗加载效果。7 条只有配置字段，另有 12 条在小游戏的脚本与配置中没有找到引用。原脚本传递命中特效路径的地方，须继续追踪到生成调用才算生效。

| 对象 | 原脚本驱动的画面 |
| --- | --- |
| 安妮斯 | 独立的大、小水波弹道，冻结挂件随目标移动，冰场按升级配置扩展 |
| 蒂娜 | 剑气、毒泽、滚石与烟尘；岩巨化使滚石从 0.4 放大至 0.6，多重岩击生成多颗 |
| 尼莉莎 | 穿透箭、首次命中后的分裂箭、沿原方向发出的冲击波 |
| 菲尼斯 | 弹射、受击目标的流血挂件、移动旋刃及升级扩张 |
| 列蒂西雅 | 普攻弹道、剑爆、队友战意挂件和防线治疗脉冲 |
| 魔物与加载 | 四类远程弹道、出生和减速效果，以及原加载相机与淡入淡出 |

[技能等级与对应表现清单](skill-upgrade-matrix.csv) 涵盖 80 条配置行，并区分实际宿主测量和调用审计。24 个 prefab 均在浏览器 WebGL 画布测得非透明像素。真关卡另实测了加载相机、滚石移动、持续滚动和烟尘。[逐项渲染图](images/effects.webp)

Unity 的粒子随机和噪声会影响单颗粒子的轨迹。受击闪色调用传给原生组件的数值已确认，现有资料没有给出该组件运行时使用的色值与包络。此部分仍待原生证据。
