- 已发布 Alpha 的网页 ZIP 与素材 ZIP 都在 GitHub Release；仓库不重复提交二进制制品。固定版用 Release 指纹复现。
- `packages/replica-runtime/` 中的兼容路径都是它的历史命名空间，入口和当前模块见 [模块地图](project-map.md)。其中仍被构建引用的诊断适配器不删、不移动内部路径。

- 已知不随 Alpha 启动的研究包括早期像素专测、历史全关回归与未完成的原生弹道、音频证据。可独立设计后续 PR；不把研究结果冒充现行玩法和发布。
