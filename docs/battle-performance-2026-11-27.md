# 战斗性能实测 · 2026-11-27

桌面使用 i5-10400、UHD 630、Windows 11、Edge 158.0.4370.33、1334 × 750。对照固定种子和原版素材，默认 Canvas、2×，实际从活动页面进关。原版规则参照为 `9e9d9f1`，本地不可变玩家包为 `b2b8d2e`，测试站为 `bc51c92`。合并前最后一次变更只同步了浏览器测试用例，线上 516 个资源均核对到本地候选。[测试站](https://luckyking232.github.io/starfall-monster-defense-web/play/) · [发布和回退规则](../CONTRIBUTING.md)

## 普通无尽

两版都在第 4 波、第 6,586 个规则帧自然结算，击退 573，选卡 16 次。相同的第 2–3 游戏分钟内，出图间隔 P95 从 105.6 降至 49.5 ms，P99 从 149.3 降至 51.1 ms，最长从 232.9 降至 68.1 ms，均无超过一秒的停顿。两局约每墙钟秒推进 2 游戏秒。此局未覆盖第 5 波。

另两局在同一重载规则帧区间各收集 20 次真实点击。点击到暂停层可见的 P95 从 68.1 降至 32.9 ms，到下一次绘制机会从 76.3 降至 46.7 ms。每次都核对暂停生效帧和继续操作。

另记录一次未跑满的候选尝试。480 秒采样点后战场消失，最后已发布第 12,794 帧。页面仍在前台，未选卡、退出或记录 Worker 异常。约 2 秒后，Windows 报告 Intel 图形驱动 0x141 超时。第一次采样未保存错误面板；触发驱动超时的进程未确定。该场保留为稳定性事件，表中三局均为实际跑满 600 秒的单局。

三局中位 P95 为 1533.4 → 231.8 ms，超过一秒的间隔为 286 → 0 次。持续 300 档每墙钟秒推进的游戏秒中位数为 0.504 → 0.840。怪海达到首轮改善门槛，P95 ≤50 ms 和 95% 倍速推进仍是后续目标。

## 半小时单局与复现

候选单局前台实测 1800.4 秒。第 0:30–5:30 与 25:00–30:00 的 15 秒区间，游戏秒／墙钟秒中位数分别为 0.808 和 0.768。两次退出后主线程堆为 10.83 / 10.87 MiB，Worker 堆为 2.99 / 3.0 MiB，Wasm 容量为 143.56 / 143.56 MiB，音频 PCM 为 108.17 / 108.17 MiB。在途页面请求为 0 / 0。图形盘点只测 JavaScript 可达句柄，驱动显存不可读取。

五个场景对照 16,790 个规则帧与 15,640 条原作音效事件。五人 15 种技能均产生原预制件，怪海 180 对连续的同后端画面逐帧一致。正式域使用 main，复测以对应 Pages 提交和实体手机回传为准。执行命令及单项回退粒度见[已批准计划](superpowers/plans/2026-11-27-battle-runtime-performance.md)。

## 剩余瓶颈

另起 65 秒独立分相，300 目标档抽到 408 个规则步、95 次实际绘制。原固定步均值 7.98 ms（弹体 3.51 ms、单位 2.39 ms）；Worker 服务时间中 53.5% 在规则、20.4% 在快照收集与编码、17.0% 在表现更新。表现内 82.5% 用在飘字。主线程战场绘制调用中位 57.8 ms、P95 74.1 ms；绘制调用包含等待图形管线的时间。两线程的数字不相加。

同机 65 秒合并 WebGL 实测出图 P95 178.5 ms、推进 73.2 游戏秒，两场 Canvas 的范围为 199.4–207.5 ms、63.60–65.33 游戏秒。目标仍需更长的同设备验证。下一轮优先拆分战场精灵／特效合成，再比较快照复用与批量编码。独立飘字回收试点在四场短局 ABBA 的 P95 降低 6.8%，推进增加 2.9%。[飘字回收草稿](https://github.com/luckyking232/starfall-monster-defense-web/pull/28)
