# 第 1 关：两个不同的战场黑屏

这是一组面向已经发布的 Alpha 1 的本地 QA 补丁。不会更新线上试玩、替换发行 ZIP、调整端上战斗规则或改变本地存档格式。

- **显示队列堆积**：加速时，自动时钟只在规则请求与显示队列都空闲后发下一批。不限制暂停、选卡等手动输入，也不取消上一帧的来源和过期校验。在慢设备上，这可能降低实际推进速度。
- **「冰封永冻」后的黑屏**：第 1 关的显示 Worker 验证原冻结状态、目标身份、暂停动画、挂载与清理，只暂不绘制原冰冻粒子。地图与单位仍走已有的原素材渲染。其他未知资源错误不吞掉。

## 验证记录

用真实规则与显示 Worker 在本地重放，Canvas2D 提交点做独立计数；不是实机手动试玩。

- 固定随机数 1：人为延迟显示 Worker 回复，旧版队列溢出停止出图；候选回放到 F4182，2 波、147 击杀，保持原失败结果。
- 固定随机数 5000：复现公开试玩同样的 11 次选卡。旧版首次请求缺失的冰冻渲染资源时停止出图；候选正常绘制地图和单位，仍在 F4181、2 波、205 击杀获胜并写入原格式存档。
- 原粒子、音频、移动端真实浏览器和 TapTap WebView 仍需单独验收。

## 本地准备

先使用既有构建工具，将已校验的 Alpha 1 ZIP 展开到一个独立目录（或用选关 QA 构建出底包），再执行：

```sh
python3 scripts/materialize_display_continuity_qa.py --alpha VERIFIED_ALPHA_DIR NEW_LOCAL_QA_DIR
# 对已经准备的选关 QA 底包改用 --startup。
```

必须保留目录边界，通过本机 HTTP 服务访问；不能把候选当作审批用或发布用 ZIP。补丁只修改五个已有文本模块，并据实更新路由指纹与本机清单。
