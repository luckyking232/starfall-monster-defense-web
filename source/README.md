# 魔物抵御战的实际复刻源码

这是当前公开审计过的项目实现，包含未完成代码；不是另写的演示游戏。路径沿用现有工程，以便维护者逐个比较和移植。由项目写的几个 Lua 观察钩子也开源了；它们不是从游戏提取的规则脚本。公开文件由 [PUBLIC-SOURCE-LIST.txt](PUBLIC-SOURCE-LIST.txt) 明列。

| 位置 | 可以修改的内容 |
| --- | --- |
| `qualified-game/revisions/r6/` | iframe/浏览器运行环境中的 Worker 接线、权威规则会话、真实升级/结算边界、暂停和帧同步。 |
| `game-session/`、`activity-flow/`、`hud-choice/` | 菜单状态和升级 UI 投影，部分是历史对照。 |
| `stage*-cpu-canvas/`、`stage-renderer/` | 地图和已核对单位的静态渲染；依赖与自身程序分开。 |
| `presentation-clock/`、`actor-bridge/` | 单位时钟、状态与渲染命令。按权威帧匹配数据，不伪造击杀或待确认结算。 |
| `qualified-game/revisions/r6/{early-fx-only-summons,stage9-fx-only-summons,stage10-fx-only-summons,stage78-frost-source-witness,temporary-20108-die}/` | 召唤、冻结、死亡的窄范围验证和可靠降级。没有把未显示的粒子写成已还原。 |
| `taptap-portable/` | 自包含静态包路径映射、审计、HTML+Worker 启动与会话内本地进度。 |

## 完整本地构建的缺件

| 输入组 | 消费者与边界 |
| --- | --- |
| 原版规则及查表 | 规则 Worker 从版本固定的脚本、配置和约定的沙盒接口启动，公开分支未分发任何提取内容。 |
| 运行时与完整性清单 | 需要受信任来源的对应 Wasmoon JS / WASM、生产配置、版本固定的加载及资源登记。当前只公开装配逻辑，期待未来贡献可自行取得且有许可的依赖锁定方案。 |
| 画面和音频 | 材质、图像、动画、字体和声音等是外部许可输入。布局可用合成数据测试，原始独特表现不能在缺件时承诺复现。 |
| 审核与参考 | 不公开含原文件的包、原始抓帧、依赖凭据、测试账户以及可直接重新下载原包的私人转交地址。欢迎提交有权分享的录屏、可复现步骤和自己创作的最小测试。 |

独立测试只用合成数据，不证明完整游戏能玩。当前已知差距包括原生弹道/特效/混音、后半关部分单位的显示、移动 WebView，另有延迟结算、视口变化与断会话恢复用例需要跑过实际页面。开源未完成实现和这些差距，是为了让协作者可以直接分工，不等最终 ZIP。
